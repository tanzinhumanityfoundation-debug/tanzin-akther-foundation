# Tanzin Akther Foundation

Build a modern, professional, mobile-first website for a humanitarian organization named "Tanzin Akther Foundation".

Tagline: "Humanity First. Together, We Can Make a Difference."

Purpose:

The organization aims to help people who need assistance with education, financial difficulties, medical needs, and other humanitarian situations.

Design:

- Clean, trustworthy, warm and professional design.

- White background with deep green and soft blue accents.

- Simple navigation and readable typography.

- Fully responsive for mobile phones, tablets and desktops.

- Use accessible buttons, clear labels and good spacing.

- Do not make it look like an e-commerce website.

Pages:

1. Home: Organization introduction, mission, categories of help and a clear "Request Help" button.

2. About Us: Mission, vision and organizational introduction.

3. Request Help: A simple form with name, contact method, category, short request description and consent checkbox.

4. Contact Us: Contact information placeholder and contact form.

5. Privacy Policy: Explain what information is collected, why it is collected and how it is protected.

6. Admin Dashboard: A separate, protected page design for authorized administrators.

Important requirements:

- Visitors must not be able to see other people's submissions.

- Do not create public request listings or public comments.

- Do not add payments, donations, chat, or user registration in this first version.

- Do not ask for national ID, bank details, passwords, medical reports or document uploads.

- Use placeholder contact information. Do not invent phone numbers, addresses or registration details.

- Do not claim that the organization is officially registered.

- Use sample data only.

- Do not connect a real database yet.

- Build the frontend and page layouts first.

Create a polished, simple website that a beginner can manage with AI assistance.
